# 默认预设：整理口语

@postprocess: zh-stutter-lite

请把下面的语音转写整理成更通顺的文本，但必须严格遵循“忠实整理”原则：

1. **只做表层整理，不做内容改写**：
   - 只允许做：删除明显口头禅、删除明显重复、补标点、轻微断句
   - 不允许翻译，不允许总结，不允许扩写，不允许缩写，不允许润色成另一种说法
   - 不允许猜测说话者真正想表达什么；拿不准时，宁可保留原文

2. **必须保留原始信息**：
   - 人名、地名、产品名、术语、英文单词、缩写、数字、时间、日期、否定词、条件词必须保留
   - 不能删除“不是、不要、不能、还没、已经、先、再、如果、但是”等会影响语义的词
   - 不能把英文改写成中文，也不能把中文改写成英文
   - 不能把原文中存在的不确定表达删掉，例如“大概、可能、好像、应该”等

3. **去重规则要保守但明确**：
   - 明显口吃式重复、连续重复、无意义重复可以删除，只保留 1 次
   - 例如：“这个这个”“就是就是”“修复修复”“你像你像”“说一点，说一点”
   - 但如果重复本身承载强调、引用或列举意义，则不要删除

4. **口头禅处理要保守**：
   - 可删除不影响语义的口头禅：嗯、啊、呃、哦、诶、那个、这个、然后、就是等
   - 只有在确认不影响原意时才删除；如果删除后意思可能变化，就保留

5. **标点符号使用规则**：
   - 疑问句必须使用问号（？）
   - 非疑问句绝对不能使用问号
   - 根据语气和停顿准确使用逗号、句号、感叹号等

6. **数字和语言处理规则**：
   - 不要擅自改写数字格式，除非只是明显的标点或空格整理
   - 中英混杂内容默认保持原样，不要主动翻译
   - 专业词汇、代码词、品牌名、模型名、API 名称优先保持原样

7. **分段和换行**：
   - 长文本可以按语义做轻微分段
   - 不要重组结构，不要把原本一句话强行改成摘要或条列

8. **输出要求**：
   - 只输出整理后的文本
   - 不要添加任何解释、说明、标题、标记或元信息
   - 如果你判断某些内容可能删错，就保留它，不要冒险删改
