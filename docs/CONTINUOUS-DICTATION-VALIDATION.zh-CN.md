# 连续听写与官方 Jev 验收记录

日期：2026-09-25。实现与测试由 Kimi K3、Grok 4.7 和 DeepSeek DSH CLI 完成；Codex 负责方案、任务分配、最终审查、文档与本机集成。未使用 GPT 子代理落产品代码或测试。Kimi 配额用尽后的工作由现有 Grok / DeepSeek CLI 继续。

## 连续录音与输入法通道

公开测试音频由上游 Confucius `resources/test.wav` 重复 15 次、段间插入 0.5 秒静音组成，总长 108.1 秒、16 kHz 单声道，共 1,729,600 个采样。通过单个 `ffmpeg -re` 以真实速度送入实际 MonitorFanout、连续识别 worker、Confucius WebSocket 服务和私有 Fcitx/GTK 输入框。没有读取或录制用户语音。

该测试同时检查：音频采样数及 SHA-256 一致、一个 BeginSession、同一 token 多次 CommitSegment、每条识别连接低于服务端 30 秒上限、25/50/75 秒后仍有预编辑、最终输入框等于完整结果且恰好一次。最终 GTK 内容按实际事件等待确认，上限 2 秒，不能仅以 D-Bus 方法返回作为应用已显示的证据。

开发中实际检出并修复了以下问题：

- websocket-client 收到 peer CLOSE 后 `connected=False`，单独调用 close 没有释放底层 TCP，下一段被模型忙碌锁拒绝；现在确保 shutdown。
- 新 GTK 输入框在第一次提交前没有 surrounding snapshot，自身提交的首次回显被误判为外部修改；现在只接受与本次提交文本完全相同、光标及锚点都在末尾的回显。其他文本、焦点或按键变化仍使会话失效。
- 把前段已提交文字作为 ASR 提示导致模型复述：相同音频有提示时产生 390 个规范化字符、18 次原句；关闭这项提示后为预期的 300 字符、15 次原句。正式 provider 不再注入前段转写，仍保留用户配置的热词；前段文本仅用于纠词上下文。

这是固定公开样本的连续性验证，不是通用识别准确率，也不等于已验证数小时录音。

## 原生输入框验证

真实私有 GTK 测试检查了多次分段、尾部提交、重复及跳号拒绝、取消、切换焦点、手动键入、点击和外来预编辑。新空输入框连续预编辑后两次分段也通过。更新后的原生插件在该组测试中退出码为 0。

真实私有 Chrome 的 textarea 和 contenteditable 各完成三次分段及一次最终提交，使用同一 token；中文、英文及非 BMP 字符 `🎯` 按顺序恰好出现一次，重复序号和跳号没有写入。插件源 SHA-256：`d5f671211d4d06aad0f6993cd893b0c5ffb030a7b896ac2999879e8803097464`；构建库：`a5cb5d0bb4e49fea005da75919a7ad0a79d4b7c3e8ef4197c492f4001fd89262`。

平台限制：部分 GTK 程序直接 set_text 不发送可用于失效判断的事件，已有问题 Recordian-22t 继续保留；有些工具包在焦点变化时自行提交预编辑。微信未实测，Cursor 编辑器场景未取得有效输入证据，不能算通过。浏览器和 GTK 结果不代表所有应用。

## 官方 Jev 与确定性格式化

通过实际 `corrector_from_args` 调用官方 `jev ask`，仅在子进程设置 `SEMIF=0` 和 `TYPESAFE_MODEL=jev-latest`，正文走标准输入。复用现有登录，没有读取或复制 Jev 密钥。111 服务器关闭后没有继续调用该服务器。

最终语境约束样例实测：7/7 应保留情形没有发请求；6/6 明确工具目标完成替换；包含脚本或调试词的人名例仍保持 Jeff。两条目标复核句中 1 条成功、1 条保留原文；另一个人名复核句保持原文。不能把保留原文的目标漏改计作纠错成功。10 次实际请求约 488～658 毫秒，配置预算 1.5 秒、上限 2 秒。分数门槛只是拒绝规则，不能保证模型判断总是正确。

“Jeff 今天怎么样”等无软件语境的提法不触发别名判断；工具语境也仍需模型通过门槛。同一句出现多个同名对象时保留原文。这里是有限候选的语境纠词，没有开启整段自由改写。

本地格式化回归包括二十五→25、编号零零一二→0012、口述 IPv4、www 点 example 点 com、已识别 scheme 的网址只改域名里的点。代码、网址路径、成语、近似数及名称等反例均有针对性测试；如三三两两、三五成群、五四运动、三番五次不会被数字化。没有明确数字语境的短串可能保持中文，不能宣称所有数字口述都无歧义。

原始证据保存在本机 `Recordian-control/.runs/20260924-continuous/reports/` 及 `logs/`。其中早期失败记录用于诊断，正式交付的结果以下述冻结检查与实际激活记录为准。
