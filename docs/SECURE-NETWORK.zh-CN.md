# 网络服务的安全部署

Recordian 的桌面控制使用私有 Unix socket；Confucius 流式识别使用本机回环地址和私有令牌。
跨电脑粘贴及旧 HTTP ASR 是另外的服务，默认仅监听 `127.0.0.1`。
安装脚本不再自动把 Ollama 暴露到所有网卡。

## 跨电脑访问

推荐把服务保留在远端回环地址，通过已有 SSH 连接建立本地转发：

```bash
ssh -N -L 24872:127.0.0.1:24872 <已有服务器别名>
```

客户端把 `remote_paste_host` 设为 `127.0.0.1`，端口为转发端口。
不要同时启动占用同一端口的本地粘贴服务。隧道为通信提供加密和服务器身份验证。

需要直接连接局域网时，服务端必须同时配置令牌和 TLS 证书，客户端必须验证证书。
服务端令牌文件只允许所属用户访问（建议 `0600`，也允许只读 `0400`）；内容为单行 ASCII 私有随机值，文件总长度不超过 4096 字符。
不要把令牌放在命令参数、日志或 Git 中。

```bash
recordian-remote-paste-agent --host <服务端绑定地址> \
  --token-file <私有令牌文件> \
  --tls-cert-file <服务端证书文件> --tls-key-file <服务端私钥文件>
```

对应的热键配置字段：

```json
{
  "enable_remote_paste": true,
  "remote_paste_host": "<证书中包含的服务端地址>",
  "remote_paste_token_file": "<本地私有令牌文件>",
  "remote_paste_tls_ca_file": "<信任的CA证书文件>"
}
```

两端的令牌内容应一致；CA 文件只包含公开证书。相对路径按热键配置文件目录解析。
客户端验证证书链和地址，不提供关闭验证的选项。

旧 HTTP ASR 和 Qwen HTTP 流式服务接受相同的 `--token-file`、`--tls-cert-file`、`--tls-key-file`。
使用 HTTPS 地址，并把令牌作为 `asr_api_key`；自行签发的证书需通过客户端信任存储或
`REQUESTS_CA_BUNDLE` 提供 CA，不能关闭 TLS 验证。
这些模型服务仍是单用户服务；需要公开服务时应在经过认证的反向代理后部署并限制入口。

## 请求边界

- 远程粘贴最多 8 个处理连接，整个请求帧有 3 秒截止时间，消息上限 1 MiB；剪贴板同步等待必须为有限的 0–3 秒。
- HTTP ASR 上传上限 16 MiB，模型只处理一个请求，忙时返回 429；生成预算不能超过服务端配置。
- HTTP 入口最多 8 个处理线程，TLS 握手最多 3 秒，请求头与请求体合计接收截止时间 10 秒；完整收到请求后不以这个传输截止时间截断模型推理。
- 旧 `/transcribe` 接口要求未压缩 WAV，最多 120 秒且不超过 1600 万声道采样；Qwen 文件上传经过有界解码，最多 120 秒。
- Qwen HTTP 流式服务最多 8 个会话，每个会话最多 120 秒的 16 kHz 音频；超限删除该会话并拒绝继续推理。
- Confucius OpenAI bridge 最多接受 30 秒音频；过大请求返回 413、无效或超预算音频返回 400。
- 未鉴权的回环 HTTP 服务拒绝外部网页 Origin 和非回环 Host，避免浏览器跨站请求和 DNS 重绑定。

旧 `/transcribe` 客户端把支持的压缩录音转换为 PCM WAV，并写入可验证的有限长度头；服务器仍拒绝畸形或超预算 WAV。

这里的文件上传与单个模型会话预算不等于桌面连续录音总时长。
Confucius 连续听写会分段建立模型会话，仍可持续录音；25 秒保护用于不支持连续分段的回退路径。

默认日志记录文字长度和结果状态，不记录 ASR/精炼/粘贴正文或实际剪贴板；UI 文本事件和显式开启的样本采集仍保留正文。
新日志文件及轮转文件只允许当前用户读写，不跟随日志文件符号链接。回环服务面向单用户主机，不能替代不同操作系统用户之间的隔离。
令牌保护入口权限，不能替代对模型依赖安全通告的处理；相关升级另见本次代码审核记录。
