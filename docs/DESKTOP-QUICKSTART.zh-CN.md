# Recordian 日常使用

本页对应本机已经配置好的 Confucius 流式识别与 Fcitx 输入法桥接。
模型服务的安装说明见 [Confucius 服务说明](../server/README-confucius.md)，
输入法插件说明见 [Fcitx 插件说明](../fcitx/recordian-commit/README.md)。

## 开始听写

1. 从程序菜单打开 **Recordian**。本机启动入口会先等待模型就绪。
2. 点击浏览器、聊天软件或编辑器里的输入框。
3. 按住 **右 Ctrl** 说话，松开后提交这一段。**右 Alt** 可切换开始与停止。
4. 文字提交后不会自动按回车；在聊天软件里，确认内容后自行发送。

推荐语言为“自动（中英）”。“边说边出字”使用输入法的预编辑能力；
应用不支持预编辑时，可能只显示预览并在结束后一次写入。
说话期间保持目标输入框的焦点，修改已输入文字时先结束当前听写。

Confucius 当前有单次音频预算，客户端会在 **25 秒**左右自动结束这一段
并提示收尾。继续说话需要松开后重新按键。这是保护性上限，尚不支持
长按时无缝连接多段。

## 常用词和设置

托盘菜单的 **常用词...** 可添加人名、项目名及英文术语，多个词用逗号
或换行分隔。明确的错词替换写成 `错词 → 正词`。常用词会用于识别提示
和上屏前的纠正；它不保证模型每次都识别正确。

**设置...** 默认展示日常选项，其他参数位于 **高级设置**。
选择识别方式后，界面只展示相关的模型和接口参数。

**使用本机推荐配置** 会填写本机 Confucius、按住说话、中英自动识别、
流式上屏及不自动回车等选项。已有口令、常用词和无关自定义项会保留。
点击 **保存并生效** 才写入配置；**取消** 放弃尚未保存的修改。
听写或处理结果期间，先结束当前输入，再保存或切换需要重启的选项。

文字润色、语音唤醒和远程粘贴默认关闭，可从高级设置按需开启。
额外热词确认也默认关闭；这不影响本地的常用词纠正。

## 启动和排查

2026-09-24 本机桌面入口为 `~/.local/bin/recordian-confucius-launch.sh`，
模型由用户服务 `recordian-confucius-asr.service` 管理，按需启动，未设置
登录自动启动。该入口用于这台已安装模型的机器，不是通用安装器。
托盘退出后模型服务可能仍驻留内存；需要释放模型显存时执行：

```sh
systemctl --user stop recordian-confucius-asr.service
```

下次通过程序菜单打开 Recordian 时，启动入口会重新启动本机模型。
查看服务状态或日志：

```sh
systemctl --user status recordian-confucius-asr.service
journalctl --user -u recordian-confucius-asr.service -n 40
```

若上一段仍在处理，请等托盘恢复就绪再开始下一段。服务忙碌拒绝后的
自动恢复仍在跟踪中（`Recordian-8ed`），不要把空结果当成成功输入。
微信及不同工具包的预编辑行为仍需逐应用验证；已有其他应用的测试
不能代替微信实测。
